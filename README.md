# AcademiaLink

## Academia–Industry Collaboration Platform

AcademiaLink is a full-stack platform designed to connect students, faculty, researchers, and industry professionals for projects, internships, research, and collaboration.

---

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Lucide React
- Recharts

### Backend
- Node.js
- Express.js
- Prisma ORM
- MySQL
